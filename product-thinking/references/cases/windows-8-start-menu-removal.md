**Decision.** Windows 8 shipped in late 2012 without the Start button, which had been on the taskbar since Windows 95. A full-screen Start screen of tiles replaced the Start menu. System commands moved to hidden "charms" that appeared after a swipe from the screen edge or a hot corner. Microsoft treated the desktop as one app, not as the main interface.

**Outcome.** Jakob Nielsen tested Windows 8 with 12 experienced PC users. He found two environments that users had to learn and remember, hidden commands, flat tiles with no cue for what was clickable, and one window at a time. Reviewers called the hot corners and edge swipes not obvious. Customer satisfaction fell to its lowest level since Windows Vista. Microsoft sold 40 million licenses in the first month, below internal targets, according to CNET. Windows 8.1 shipped in October 2013. It brought the Start button back and let users boot straight to the desktop. Many of the 8.1 interface changes were responses to criticism of Windows 8.

**Lesson.** If you remove a control that users rely on and hide its replacement behind gestures, they lose the way to do basic tasks, so test the change with real users first.
